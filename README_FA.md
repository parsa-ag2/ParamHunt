# ParamHunt

[English](README.md) | **فارسی**

![status](https://img.shields.io/badge/status-in%20development-orange) ![stack](https://img.shields.io/badge/stack-WXT%20%2B%20React-blue) ![mv3](https://img.shields.io/badge/manifest-v3-green)

یک **افزونه کروم برای پژوهش امنیت وب** — ساخته‌شده برای باگ‌بانتی‌ها و پژوهشگران امنیتی که کارشان داخل مرورگر است. ParamHunt رفتار یک وب‌اپلیکیشن را مشاهده می‌کند (پارامترها، درخواست‌های HTTP، DOM، پیام‌های postMessage، جاوااسکریپت و حافظه‌های مرورگر) و این مشاهدات را به یک فهرست یافته‌های منظم و قابل‌خروجی تبدیل می‌کند.

> ⚠️ **فقط برای استفاده مجاز.** ParamHunt یک ابزار مشاهده است، برای سامانه‌هایی که مجاز به تستشان هستید (برنامه‌های باگ‌بانتی، اپلیکیشن‌های خودتان، مجوز کتبی). این ابزار هرگز حمله نمی‌کند — فقط مشاهده می‌کند.

## 📌 وضعیت فعلی (v0.0.1)

ParamHunt **در حال توسعه فعال** است. افزونه امروز **نصب و اجرا می‌شود** و کل معماری آن آماده است (موتور ماژولار، پیام‌رسانی تایپ‌شده، لایه ذخیره‌سازی و هر سه رابط کاربری). ماژول‌های تحلیلی مرحله‌به‌مرحله ساخته می‌شوند — جدول صادقانه زیر را ببینید.

## 📥 نصب (بدون Node.js، بدون npm، بدون ترمینال)

**برای نصب و استفاده از ParamHunt نیازی به نصب Node.js یا npm و اجرای هیچ دستور ترمینالی نیست.**
داخل مخزن گیت‌هاب، پوشه **آماده‌ی نصب** افزونه به نام `chrome/` قرار دارد. فقط به Chrome/Chromium نیاز دارید.

### مرحله ۱ — دانلود

در همین صفحه مخزن، روی دکمه سبز **`Code`** کلیک کنید → **`Download ZIP`**.
(یا اگر git دارید: `git clone https://github.com/parsa-ag2/ParamHunt.git`)

### مرحله ۲ — استخراج فایل

فایل ZIP دانلودشده را Extract کنید. پوشه‌ای به نام `ParamHunt-main` خواهید داشت که داخل آن، پوشه‌ای به نام **`chrome`** وجود دارد.

### مرحله ۳ — ورود به صفحه افزونه‌ها

در نوار آدرس کروم این آدرس را باز کنید:

```
chrome://extensions/
```

### مرحله ۴ — فعال کردن Developer Mode

کلید **`Developer mode`** را (بالا-سمت راست) روشن کنید.

### مرحله ۵ — بارگذاری افزونه

روی **`Load unpacked`** کلیک کنید (بالا-سمت چپ) و سپس پوشه **`chrome`** را از داخل مخزن انتخاب کنید — پوشه‌ای که فایل `manifest.json` مستقیماً داخلش است.

> ✅ درست: `…/ParamHunt-main/chrome`  ❌ اشتباه: `…/ParamHunt-main` (اینجا manifest.json نیست)

### مرحله ۶ — شروع استفاده

- آیکون ParamHunt را در نوار ابزار کروم باز کنید (آیکون پازل 🧩 → آن را Pin کنید) تا **داشبورد popup** باز شود.
- روی هر صفحه **F12** بزنید → در پنجره DevTools تب **ParamHunt** را ببینید (سطح پنل).
- از صفحه جزئیات افزونه (`chrome://extensions/` → Details → Extension options) صفحه **Options** را باز کنید.

## 🔐 مجوزها و حریم خصوصی

| مجوز | چرا لازم است |
|---|---|
| `storage` | ذخیره‌سازی محلی یافته‌ها و تنظیمات شما داخل مرورگر |
| `tabs` / `activeTab` | تشخیص تب در حال بازرسی؛ اجرای عملیات با کلیک کاربر |
| `scripting` | تزریق کد تحلیل به صفحه‌هایی که خودتان برای بازرسی انتخاب می‌کنید |
| `webRequest` | مشاهده متادیتای درخواست‌های شبکه‌ی تبِ در حال بازرسی |
| `cookies` | نمایش ویژگی‌های کوکی‌ها (Secure/HttpOnly/SameSite) در بازرس حافظه |
| دسترسی میزبان (`<all_urls>`) | ابزار پژوهش برای هر تارگتی که انتخاب می‌کنید؛ لیست سفید scope داخل خود افزونه تعیین می‌کند واقعاً چه چیزی مشاهده شود |

**حریم خصوصی:** همه‌چیز روی سیستم خودتان می‌ماند. نه تله‌متری، نه آنالیتیکس، نه سرور خارجی. یافته‌ها در حافظه محلی مرورگر ذخیره می‌شوند و فقط زمانی از سیستم شما خارج می‌شوند که خودتان خروجی بگیرید.

## ❓ سؤالات متداول

**آیا این ابزار حمله است؟** خیر. ParamHunt فقط مشاهده می‌کند؛ payload حمله نمی‌فرستد و ترافیک را مسدود یا دستکاری نمی‌کند.

**چرا Developer mode و Load unpacked؟** افزونه در حال توسعه فعال است و هنوز به Chrome Web Store منتشر نشده. بارگذاری unpacked روش استاندارد اجرای آن است.

**روی فایرفاکس کار می‌کند؟** زنجیره ساخت WXT از فایرفاکس هم پشتیبانی می‌کند (`npm run build:firefox` برای توسعه‌دهندگان)، اما نسخه‌های فعلی فقط برای Chrome/Chromium هدف‌گذاری شده‌اند.

**کروم هشدار «Disable developer mode extensions» می‌دهد؟** برای افزونه‌های self-loaded این پیام طبیعی است و ربطی به ویروس ندارد.

## 🐞 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| هنگام Load unpacked پیام «Could not find manifest» | پوشه ریشه مخزن را انتخاب کرده‌اید — پوشه **`chrome`** را انتخاب کنید |
| افزونه در نوار ابزار دیده نمی‌شود | آیکون پازل 🧩 → ParamHunt را Pin کنید |
| به‌نظر می‌رسد هیچ اتفاقی نمی‌افتد | کنسول DevTools (F12) را باز کنید و دنبال لاگ‌های `[ParamHunt]` بگردید |
