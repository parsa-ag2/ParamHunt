# ParamHunt

[English](README.md) | **فارسی**

یک افزونه کروم برای پژوهش امنیت وب: **پارامترهایی که یک وب‌اپلیکیشن در معرض نمایش می‌گذارد را کشف و دسته‌بندی می‌کند** — از URL، فرم‌ها (شامل inputهای مخفی)، DOM زنده و جاوااسکریپت صفحه — در حالی که تارگتِ مجازِ خود را مرور می‌کنید.

> ⚠️ ParamHunt یک ابزار **فقط-مشاهده** است و برای تست‌های مجاز طراحی شده (برنامه‌های باگ‌بانتی، اپلیکیشن‌های خودتان). هرگز فرم را submit نمی‌کند، payload نمی‌فرستد و درخواست‌ها را تغییر نمی‌دهد.

## قابلیت‌های فعلی

- **موتور کشف پارامتر** — جمع‌آوری نام پارامترها از همه منابع سمت-کلاینت صفحاتی که باز می‌کنید:
  - پارامترهای query و fragment در URL
  - فرم‌های HTML: اکشن، متد، input/select/textarea و **inputهای مخفی**
  - کنترل‌های مستقل DOM و اتریبیوت `data-param`
  - منابع جاوااسکریپت: literalهای URL، استفاده از `URLSearchParams`، کلیدهای آبجکت‌های params/config (تحلیل متنی، بدون اجرا)
- **حذف تکراری‌ها (Dedup)** — پارامتری که در صفحات/منابع مختلف دیده شود در یک ردیف ادغام می‌شود؛ با تعداد تکرار، تفکیک منبع، متد/نوع input و سطح اعتماد (confidence).
- **کنترل Scope** — پیش‌فرض فقط origin سایت فعلی؛ از صفحه Options با allowlist (دامنه یا الگوی glob) و exclusions گسترش/محدود کنید. exclusions همیشه برنده‌اند و صفحات خارج از scope هرگز جمع‌آوری نمی‌شوند.
- **پنل DevTools** — F12 → تب *ParamHunt*: جدول زنده پارامترها با نشان منبع، confidence، تعداد تکرار، نمای جزئیات، فیلتر متنی، دکمه **Rescan** دستی و پاک‌سازی.
- **Popup** — وضعیت scope تب فعلی، شمارنده پارامترهای کشف‌شده و وضعیت موتور.
- **ماندگاری** — یافته‌ها بعد از ری‌استارت مرورگر هم می‌مانند (حافظه محلی مرورگر، dedup شده).
- **Rescan دستی** — جمع‌آوری فرم‌ها/فیلدهایی که به‌صورت پویا اضافه می‌شوند.

## نصب

**برای نصب و استفاده از ParamHunt نیازی به نصب Node.js یا npm و اجرای هیچ دستور ترمینالی نیست.**
داخل مخزن، پوشه **آماده‌ی نصب** `chrome/` وجود دارد که نسخه کامپایل‌شده افزونه است (`manifest.json` مستقیماً داخل آن).

1. **دانلود**: دکمه سبز **`Code`** → **`Download ZIP`** (یا `git clone https://github.com/parsa-ag2/ParamHunt.git`).
2. **استخراج** فایل ZIP — پوشه‌ای مثل `ParamHunt-main` می‌گیرید که داخلش پوشه `chrome` است.
3. آدرس `chrome://extensions/` را در Chrome/Chromium باز کنید.
4. کلید **`Developer mode`** را (بالا-سمت راست) روشن کنید.
5. روی **`Load unpacked`** کلیک کنید و پوشه **`chrome`** استخراج‌شده را انتخاب کنید — پوشه‌ای که `manifest.json` مستقیماً داخلش است (نه ریشه مخزن).
6. **استفاده**: تارگت خود را مرور کنید؛ F12 → تب **ParamHunt** → **Rescan**.

## حریم خصوصی

همه داده‌ها روی سیستم شما می‌ماند: یافته‌ها در حافظه محلی مرورگر ذخیره می‌شوند و فقط با خروجی‌گیری خودتان از سیستم خارج می‌شوند (رابط خروجی‌گیری در حال توسعه است). بدون تله‌متری، بدون سرور خارجی. افزونه مجوزهای `storage`، `scripting`، `webRequest`، `tabs`، `activeTab`، `cookies` و دسترسی میزبان برای تارگت‌های شما را می‌خواهد؛ سیستم scope تعیین می‌کند واقعاً چه چیزی جمع‌آوری شود.
